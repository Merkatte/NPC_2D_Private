# 공통 알림 HUD

서로 다른 기능에서 발생한 알림이 화면 오른쪽 위의 같은 줄을 사용한다. 건설 완료와 군사 훈련 완료의 UI 연결부는 각 도메인의 성공 이벤트를 받아 지역화 키와 표시 인자를 공통 HUD에 전달한다. 알림이 접수된 순서로 하나의 큐에 쌓이므로 공사 다음에 훈련이 끝나면 두 메시지를 그 순서로 표시한다.

## 연출과 수명

NotificationToastHUD.cs가 대기열·표시 중인 행·재사용 행과 DOTween을 소유한다. 각 행은 왼쪽에서 오른쪽으로 32 UI 단위 이동하며 나타나고, 사라질 때도 오른쪽으로 빠져나간다. 기존 행이 아래로 한 칸 내려간 뒤 다음 행이 등장한다. 각 이동은 0.18초, 표시는 등장 시점부터 4초이고 모두 UI 시간을 사용한다. 최대 3행이며 밀려나는 가장 오래된 행은 퇴장 연출이 끝날 때까지 한 자리를 차지한다.

## 변경 유형별 최소 확인 범위

- 알림 연출·큐·풀 수명 변경은 NotificationToastHUD와 DefenseTest의 HUD 프리팹을 확인한다.
- 발행 조건은 [건설 UI](../../Settlement/Construction/UI.md) 또는 [군사 훈련](../../Combat/Defense/Military_Training.md)을 확인한다.
