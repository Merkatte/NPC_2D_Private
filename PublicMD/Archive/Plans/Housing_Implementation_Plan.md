# 주택 구현 승인 계획 — 2026-10-08

상태: 사용자 승인 구현 완료. Unity 컴파일·기존 건설/자원/탐색 검사와 독립 리뷰 Approve를 확인했다. 최종 밸런스와 사람 플레이/화면 확인은 미확정이다. 실제 결과는 ../../Status/PROGRESS.md를 따른다.

## 확정 규칙

- BuildingTest에만 주거 서비스를 연결한다. FarmerTest/GuardTest 씬과 미연결 기존 행동은 유지한다.
- 주민은 소환 후 빈자리 있는 집에 배정되어 귀가한다. 무주택 배정 순서는 현재 총불만도 내림차순, 동률 등록 순서다. 도달 가능한 가장 가까운 집을 선택하고 동거리 집은 등록 순서로 결정한다. 이동 전 입주를 확정하며 기존 주민을 자동 이사시키지 않는다.
- NPCManager는 주민 등록/해제/읽기 목록, HousingManager는 주택 등록과 배정 조정, HousingAssignmentPolicy는 정렬/선택, House는 단계/효과/정원/입주자를 소유한다.
- 할 일이 없으면 집에 머물고 일이 생기면 업무로 돌아간다. 업무 피로는 여관에서 시간 비례로 완전 회복한다. 무주택자는 여관을 이용해도 무주택 원인이 유지된다.
- 집에서도 허기/갈증은 증가하고 기존 욕구 판단으로 외출한다. 불만 회복 보너스는 입주 중 외출해도 적용하되 기존처럼 해소된 원인에만 적용한다. 피로/선택적 욕구 회복은 실제 집 체류 중만 적용한다.
- HomeStayAction은 귀가 이동과 체류 실행을 담당한다. selector가 업무/생활 재판단을 소유하고 WorkerNPC는 공통 주기 hook과 queue lifecycle만 소유한다. ActionContext의 단일 provider 계약은 유지한다.
- 단계별 옵션은 완전한 명시 목록이며 자동 상속하지 않는다. 정원은 절대값, 회복은 초당 보너스다. 한 단계의 동일 효과 중복은 오류이며 정원은 감소하지 않는다. 효과 enum 안정 ID를 사용한다.
- BuildingData/BuildingCost를 단계별로 재사용한다. HouseTierData(tier,buildingId), HousingOption(optionId,effectType,value), HouseTierOption(tier,optionId), 생활 설정 CSV를 추가한다. 신규 등록 아이템의 비용 사용은 CSV만 수정한다. 새 효과 종류/생산 경로는 별도 코드다.
- 빈 부지는 1단계만 건설한다. 한 단계씩 기존 건축가 공사로 업그레이드한다. 비용 선불/예약/FIFO/환불 규칙을 재사용한다. 업그레이드 중 기존 객체/거주/효과를 유지하고 완료 시 단계/효과/sprite를 함께 적용한다. 취소는 기존 Completed 상태로 복귀한다. 완료 적용 실패는 기존 집을 보존하고 재시도한다.
- 집 클릭 창: 단계/정원/거주민/현재 효과, 하단 다음 단계 비교/동적 복수 재료/업그레이드, 공사 진행/취소, 최고 단계 표시. 기존 건설 목록에 주택을 추가하고 스크롤을 지원한다.

- 코드 역할은 주택/데이터/생활과 건설/UI로 분리한다. 배선 역할은 컴파일 후 House prefab, 설정 SO, popup, BuildingTest와 ConstructionPopup만 조립한다. 기존 6개 빈 부지/2 Builders/초기 재고와 기존 주택 그림을 유지한다. 전체 BuildingConstructionSetup을 재실행하지 않는다.

- 새 production C#의 Systems 주 소유 문서를 지정하고 관련 기존 문서/PLAN/PROGRESS를 갱신한다.
