# Terrain 제작 기억과 견본 재사용

이 문서는 다음 Terrain 작업이 이미 확인한 실패를 반복하지 않고, 실제로 통과한 견본이 생기면 그 원본과 제작 방법을 찾아 재사용하기 위한 짧은 색인이다. 일반 제작·판정 규칙은 [SKILL.md](../SKILL.md), 계약 항목은 [tile-contract.md](tile-contract.md)가 소유한다.

## 현재 사용자 화풍 선호 — 2026-11-02

사용자는 작은 연못 견본을 본 뒤 **게임 특성상 부드럽고 따뜻한 느낌을 선호하며, 반드시 픽셀 아트여야 한다**고 명시했다. 이 선호를 이전 B 분위기의 임시 선택보다 우선한다. 특정 팔레트나 수정 결과까지 승인한 것은 아니다.

- 부드러움은 선명한 논리 픽셀을 유지한 색 관계·형태·음영 덩어리로 표현한다. 블러, 안티앨리어싱이나 연속적인 회화식 그라데이션으로 대체하지 않는다.
- 다음 조정 후보: 따뜻한 녹색과 흙색, 지나치게 어둡지 않은 물, 과도한 명암 대비를 줄인 재질 음영, 덜 날카로운 풀 덩어리와 완만한 물가 형태. 이는 선호를 구현하기 위한 제안이며 특정 색상값·파스텔풍·전체 단색화를 확정한 것이 아니다.
- 현재 연못은 연결·픽셀 제작 방식의 시험 결과로 보존한다. 새 선호에 맞는 최종 화풍으로 자동 승인하지 않는다. 색·형태를 바꾸면 관련 이웃 타일에도 일관되게 반영하고 영향받은 연결·반복·표현을 다시 확인한다.

### 식생·환경 표현에 대한 후속 요구

사용자가 추가한 “풀과 돌멩이”는 두 종류만을 뜻하지 않는다. **식생과 환경 요소 전반을 활용해 지형에 자연스러운 변화와 장소감을 더하는 방향**을 원한다. 위의 부드럽고 따뜻한 픽셀 화풍과 함께 적용한다.

- 풀 무더기·작은 꽃·관목, 물가의 갈대·수생 식물, 자갈·작은 바위·낙엽 등은 적용 가능한 예시다. 전부 필수 목록으로 고정하거나 특정 두 종류로 제한하지 않는다. 후속 제작 범위와 장소에 맞게 필요한 종류를 선택한다.
- 실제 표현안에서는 장식이 적은 바탕과 식생·환경 요소가 있는 변형을 함께 두어 이동 공간의 가독성을 유지하고 군집·빈 공간에 차이를 준다. 다양성 요청을 모든 타일을 빽빽하게 채우라는 뜻으로 해석하지 않는다.
- 작은 지면 요소는 기본적으로 요청한 Terrain 타일에 포함된 완성 변형으로 제공한다. 별도 장식 시트만 전달하고 사용자에게 직접 배치하도록 넘기지 않는다. 새 큰 장애물·충돌·이동 규칙까지 요구된 것으로 확대 해석하지 않는다.
- 장식 변형도 연결 픽셀과 기존 재료 점유를 유지하고 기본 타일과 섞어 확인한다. 장식을 이용해 끊어진 경계나 셀별 명암을 가리는 것으로 연결 검증을 대신하지 않는다.
- 이 요구는 이후 제작 방향이다. 아래의 기존 10종 연못 시험에 해당 식생·환경 변형이 이미 제작되거나 검증됐다는 뜻은 아니다.

### 길의 구성에 대한 명시적 요구

사용자는 길을 한 타일 안에 전부 그리지 말고, 흙·물처럼 **여러 타일이 합쳐져 하나의 길이 되게** 하라고 명시했다. 길 양쪽 가장자리, 흙 중앙, 바깥/안쪽 코너를 별도 지형 타일로 제작한다. 흙 중앙을 여러 장 붙여 폭을 바꾸고 굽이·갈림길·공터도 같은 지형 타일의 조합으로 표현한다. 한 셀 안에 길의 전체 폭이나 완성된 T자·십자·굽이·막다른 길을 그린 도로 스프라이트로 대체하지 않는다.

## 기록과 재사용 원칙

- 작업별 상세 기록은 해당 출력 폴더의 기존 작업 기록 하나에 유지한다. 여기에는 결과, 재사용 가능한 범위, 원본·기록 링크만 요약한다. 별도 검사 도구나 중복 보고서를 만들지 않는다.
- 기록 상태는 **제안/미실행**, **진행 중**, **실패**, **통과**를 구분한다. 생성 완료나 연결 검사 성공만으로 전체 통과로 올리지 않는다. 작업자의 제출과 루트의 판정, 사용자의 명시적 스타일 선택도 구분한다.
- 통과 견본의 상세 기록에는 기준 이미지와 선택 근거, 원본/편집 가능한 파일, 실제 타일 ID·크기·논리 픽셀 그리드, 연결에 사용한 원본 픽셀 좌표, 실제 사용한 도구·조작/명령·생성 프롬프트 위치를 남긴다. 실행하지 않은 방법을 성공한 제작법으로 기록하지 않는다.
- 같은 기록에 정확한 타일 복사로 만든 반복·혼합·경계 조립 이미지, 검사한 방향/조합, 화풍 비교와 루트 판정, 실패·미검증 범위를 남긴다. 수치 비교는 검사한 픽셀의 일치 근거이며 그림 품질의 통과 근거를 대신하지 않는다.
- 재사용할 때 관련 원본과 증거가 실제로 존재하고 현재 요청과 맞는지 확인한다. 파일이 없거나 원본이 바뀌었다면 과거 기록만으로 통과를 주장하지 않는다. 통과한 범위를 넘는 재료·코너·변형은 새로 확인하되, 바뀌지 않은 범위의 검사를 반복하지 않는다.
- 새 실행 결과가 생기면 아래 상태와 링크를 갱신한다. 실패 원본은 성공 견본으로 덮어쓰지 않는다. 출력 이미지도 함께 보존되어야 기록을 다시 활용할 수 있으며, 문서 작성만으로 Git 커밋·푸시가 된 것은 아니다.

## 2026-11-02 이전 두 안의 실패 기록

아래 두 안은 실패 사례와 제한된 연결 근거다. 이후 작은 연못 시험의 결과는 다음 절에서 별도로 관리한다. 실패한 두 안을 새 시험의 통과 범위에 포함하지 않는다.

| 시도 | 결과와 원인 | 다음 작업에서의 사용 범위 |
|---|---|---|
| A-rich 흙 견본 | **실패.** 기존 흙의 잘라 붙이기는 눈에 띄는 반복 무늬를 남겼다. 새로 생성한 흙에도 흐릿한 블록 경계와 미세한 명암이 남아 요구한 픽셀 표현에 미달했다. 경계·전체 시트로 확장하지 않았다. | 자르기·경계 복사만으로 원본 전체의 화풍 결함을 해결할 수 없다는 실패 근거. 승인된 픽셀 원본으로 사용하지 않는다. |
| B-quiet 연못 및 확장 | **실패.** 검사한 물가·흙 경계 연결은 개선됐지만, 단색 바탕과 단순 도형으로 재작성하면서 원래 질감·장식 품질을 잃었다. 루트가 최소 연결 개선을 보고 확장을 허용한 판단도 문제였다. | 실제 연결 픽셀을 양쪽 모서리에 물려주는 방법과 해당 검사 범위만 참고한다. 완성 화풍이나 전체 제작 성공 사례로 재사용하지 않는다. |

## 작은 연못 견본 — 시험 범위 통과, 사용자 최종 화풍 미승인 (2026-11-02)

사용자가 작은 견본 제작 테스트 재시작을 요청하여 아래 범위를 제작했다. 루트가 실제 확대 이미지와 검사 결과를 확인하여 **64px 물·물가 견본의 픽셀 표현과 시험한 연결 범위**를 통과로 판단했다. **사용자의 최종 화풍 승인을 받은 것은 아니며**, 다른 Terrain 작업의 고정 규격으로 적용하지 않는다.

이번 실행은 [단일 제작 기록](../../../../output/ArtDirection/TerrainPondTrial20261102/trial-record.md)에 실제 조작·원본·연결 좌표·검사를 보존한다. ImageMagick의 네이티브 드로잉 입력(MVG)으로 실제 64×64 픽셀에서 질감과 경계를 작성했다. 이미지 생성, 고해상도 그림 축소·양자화, 이전의 평평해진 B 원본 재사용은 하지 않았다. MVG는 편집 가능한 드로잉 입력이며 Aseprite 파일이나 사람 작가의 수작업이라는 뜻은 아니다. 공통 수정 한도 2회 중 1회를 사용하여 직선 물가의 작고 규칙적인 굴곡을 줄였으며 추가 확장은 하지 않았다.

| 항목 | 이번 시험 범위 |
|---|---|
| 목적 | 한 화풍에서 그림 품질과 실제 타일 연결을 동시에 유지할 수 있는지 확인 |
| 비교 이미지 | 시험 당시 [이전 B 장면](../../../../output/ArtDirection/TerrainDualConcept20261102/B-quiet/scene-B-v2.png)의 차분한 잔디·흙·물 분위기를 후보로 사용했다. 후속 제작은 위의 사용자 선호인 부드럽고 따뜻한 픽셀 아트를 우선한다. 이 이미지나 현재 견본의 최종 화풍 승인을 뜻하지 않음 |
| 유지할 표현 | 색감뿐 아니라 풀의 형태, 흙 질감, 물가 두께, 선명하고 의도적인 픽셀 표현. 최근의 평평해진 B 결과는 목표 화풍에서 제외 |
| 실제 구성 | 64×64 원본 10개: 물 W0/W1, 물가 직선 N/E/S/W, 연못 외곽 NW/NE/SE/SW. 원본 시트 320×128, 5열×2행. 재료 점유·연결 좌표는 단일 제작 기록 참조 |
| 이번에 제외 | 별도 꽃·바위 계열, 다른 땅 재료, 깊이 전환, 물가 오목 코너 등 범위를 늘리는 제작. 이 견본의 통과로 해당 연결까지 보장하지 않음 |
| 전달할 근거 | 동일 타일을 가로·세로 반복하고 변형을 섞은 물 표면, 직선 네 방향과 모서리 양쪽 연결을 포함한 작은 연못. 별도 생성한 풍경은 연결 근거로 사용하지 않음 |
| 통과 조건 | 원본의 픽셀 화풍, 중앙 반복·혼합, 직선·모서리 연결, 수정 후 표현 품질을 모두 충족하고 루트가 실제 결과를 확인. 사용자는 기술 좌표 대신 원하는 그림 느낌이 유지됐는지를 판단할 수 있도록 기준 이미지와 함께 제시 |
| 실패 시 | 실패한 타일과 직접 영향받는 연결만 기존 작업 공통 수정 한도 안에서 수정. 해결되지 않으면 구체적인 제작 한계와 결과를 기록하고 전체 시트로 확장하지 않음 |

### 결과와 재사용 범위

- [실제 타일 조립 연못 4배 확대](../../../../output/ArtDirection/TerrainPondTrial20261102/pond-4x.png), [이름을 붙인 시트 4배 확대](../../../../output/ArtDirection/TerrainPondTrial20261102/pond-tiles-labeled-4x.png), [원본 시트](../../../../output/ArtDirection/TerrainPondTrial20261102/pond-tiles-native.png), [물 반복·혼합](../../../../output/ArtDirection/TerrainPondTrial20261102/water-evidence-4x.png).
- [픽셀 비교 결과](../../../../output/ArtDirection/TerrainPondTrial20261102/pixel-readback.txt): 4×4 연못에서 맞닿는 24개 경계, 수정 전후 직선 양끝 8개 연결 스트립, 원본 대비 시트 10개 셀 모두 AE=0. 루트는 최종 연못·시트·물 표면도 직접 확인했다. 네 직선 방향과 외곽 코너 네 방향의 양쪽 연결을 포함한다.
- 육안 판단: 흐릿한 픽셀 경계나 사각 셀별 명암 없이 잔디 덩어리와 흙 단면을 유지했다. 수정 후 작은 등간격 물가 굴곡은 줄었지만 **큰 굴곡·풀 배치·물결의 타일 반복감은 남는다.** 자연스러운 넓은 맵 전체의 완성도나 사용자가 원하는 최종 화풍까지 확정하지 않는다.
- 동일한 64px 스타일과 연결을 사용하는 후속 작업에는 원본 타일, MVG 입력, 실제 양끝 연결 픽셀과 현재 검사 결과를 재사용할 수 있다. 새로운 물가 변형은 양끝을 유지하면서 내부 표현을 바꾸되 변경된 조합을 확인한다. 이 시험에서 제외한 오목 코너, 깊이 전환, 다른 재료, Unity Tilemap 동작은 미검증이다.
