# Warm Pixel UI 이미지

선택한 ② 따뜻한 픽셀 시안의 UI 조립용 PNG입니다. 텍스트, 숫자, 아이템 아이콘을 배경 이미지에 합치지 않습니다.

`preview.png`에서 전체 부품을 확인할 수 있습니다. 미리보기의 체크무늬는 투명 영역 표시이며 개별 부품에는 포함되지 않습니다. 최종 PNG는 사용자 승인에 따라 픽셀 단위로 보정했으며 반투명 번짐 없이 0/255 alpha를 사용합니다.

| 파일 | 용도 |
| --- | --- |
| 01-window.png | 공통 창 배경 |
| 02-summary-panel.png | 고정된 오른쪽 판매 내역 패널 |
| 03-button-primary.png | 판매하기 등 주요 버튼 배경 |
| 04-button-secondary.png | 취소·확인 등 보조 버튼 배경 |
| 05-button-square.png | 수량 감소·증가 공용 사각 버튼 배경 |
| 06-quantity-field.png | 판매 수량 입력칸 배경 |
| 07-icon-close.png | 닫기 X 아이콘 |
| 08-scroll-track.png | 왼쪽 상품 목록의 세로 스크롤바 배경 |
| 09-scroll-thumb.png | 세로 스크롤바 손잡이 |

버튼 문구, +/− 기호, 수량, 상품명은 선택할 픽셀 폰트로 별도 표시합니다. 당근·감자 아이콘은 기존 프로젝트 에셋을 사용합니다.

창 배경 안에 목록이나 버튼을 합치지 않아 화면 크기와 품목 수에 맞춰 배치할 수 있습니다. 왼쪽 목록은 세로 스크롤 영역, 오른쪽 판매 내역과 판매하기 버튼은 고정 영역으로 사용하는 구상입니다.

## 범위

- 이미지 제작만 포함합니다. 실제 스크롤·드래그·버튼 동작, 씬 배선, Unity importer 적용은 포함하지 않습니다.
- `import-spec.json`은 실제 파일 크기/투명도와 권장 import 및 9-slice 설정을 정리합니다. 실제 Unity 표시 확인 전의 제안값입니다.
- `Assets` 폴더와 기존 UI는 변경하지 않습니다.
